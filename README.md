# 屿作 · 离线工具作品集

这是一个可本地打开、可独立托管的中文静态作品展示页。它介绍四件精选工具，附带一只原创橘猫像素动画和三段原创 WAV 音效样品。

## 预览与构建

直接打开 `index.html` 即可浏览，不需要开发服务器或联网。页面只加载本目录内的 CSS、JavaScript、截图和音频；GitHub 作者资料链接只有在访客主动点击时才会打开。

作品集页面预览见 [`preview.png`](preview.png)。

使用 Node.js（无第三方依赖）运行：

```sh
node scripts/build.cjs
```

脚本从本目录现有文件生成：

- `dist/free-samples.zip`：猫的项目 JSON、spritesheet、逐帧 PNG、metadata，三个 WAV 和许可/来源说明。
- `dist/atelier-showcase.zip`：作品集页面、截图、免费样品和相关说明，不含完整产品应用源码。
- `dist/SHA256.json`：逐项列出展示源文件、截图、样品和两个 ZIP 的 SHA-256。该清单放在展示 ZIP 外，以避免自引用。

压缩包以固定文件顺序和时间戳创建，重建结果可复现。源码中包含免费样品 ZIP 和校验清单；克隆后运行上述命令生成完整展示 ZIP。展示 ZIP 内也包含自足的 Node 内置模块构建脚本。

## 精选作品

- **核单台**：在本机按订单号对比两份 CSV 的金额，定位差异、重复及缺失项。它不连接支付平台，也不处理收款。
- **交接册**：把软件实施、培训和自由职业交付流程整理成带截图步骤的客户手册，支持实色隐私遮盖并导出静态 HTML。
- **交付清单**：在本机核对交付文件、版本差异与 SHA-256 信息；不会上传、移动或修改原文件。
- **帧匣 × 声匣**：像素帧动画绘制与算法合成短音效。展示页只开放少量样品下载。
- **纸牌铺**：编辑学习卡、破冰卡与桌游原型卡，预览 A4 双面排版并导出离线打印稿。打印前应先校样。

页面还列出潮汐小屋、双潮信号、幕布与小生意工具箱作为其他试作。**展示包不包含这些产品的完整代码或交付包。**
